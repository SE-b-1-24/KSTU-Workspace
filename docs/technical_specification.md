# Техническое задание (Версия 2.0)
**на программное обеспечение «Корпоративная система мониторинга, управления проектной деятельностью и базой знаний»**

## 1. Концепция системы
Система предназначена для обеспечения изолированного  рабочего рабочего пространства любых отделов (ИТ, HR, маркетинг, учебные кафедры). Цель — устранение фрагментации контекста путем объединения задач, проектной документации, графиков в единый единый ресурс с интеллектуальным поиском.

*В отличие от Jira, наша система объединяет задачи и базу знаний в граф и использует LLM для мгновенного поиска информации.*

## 2. Функциональные требования

### 2.1. Ядро, безопасность
* Регистрация и авторизация. 
* Ролевая модель доступа (Владелец пространства, Редактор/Участник, Читатель).
* Управление изолированными рабочими пространствами (Projects/Workspaces).
* Локальное хранилище файлов: загрузка и прикрепление любых файлов (картинок, документов) к задачам (Drag-and-Drop).
* Модульная архитектура: администратор может включать/выключать модули (Гант, ИИ, Email-уведомления) для конкретного проекта.

### 2.2. Таск-трекер
* Создание карточек задач с атрибутами: Название, Описание, Исполнитель, Сроки, Теги.
* Визуализация в виде интерактивной Канбан-доски с возможностью Drag-and-Drop перемещения карточек.
* Опциональное включение вида "Диаграмма Ганта" для визуализации временных шкал проекта.

### 2.3. База знаний и Корп. Обучение (Wiki)
* Встроенный Markdown-редактор для ведения проектной документации и обучающих материалов.
* **Двунаправленные ссылки:** Синтаксис `[[Название]]` для связывания задач с требованиями напрямую в тексте.
* Визуализация всех документов и задач в виде интерактивного 2D-Графа связей.

### 2.4. Автоматизация (Git Webhooks)
* API-эндпоинт для интеграции с внешними системами контроля версий (GitHub/GitLab).
* Автоматическая смена статуса задачи на Канбан-доске при упоминании ID задачи в коммите разработчика.

### 2.5. Модуль «ИИ-ассистент» (RAG LLM)
* Контекстный чат-бот для сотрудников проекта.
* Бот отвечает на вопросы, основываясь исключительно на внутренних документах и задачах конкретного проекта (технология RAG + векторная БД).
* Бот обязан указывать ссылки на первоисточник в базе знаний при ответе на вопрос.

## 3. Технологический стек
* **Backend:** Python (FastAPI), SQLAlchemy, интеграция с LLM (OpenAI API / Ollama).
* **База данных:** PostgreSQL (с расширением `pgvector` для работы ИИ). 
* **Frontend:** TypeScript, React (или Vue 3), Tailwind CSS.
* **Инфраструктура:** Docker, Docker Compose для безопасного On-Premise развертывания.
